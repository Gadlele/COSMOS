COSMOS off air

Radio test player

This page is a PLAYER on RADIO COSMOS. On air, it pairs with another player: one plays the PAD, the other the BELLS, chosen at random. An FM-1 set as a PLAYER can be its partner; one set as a LISTENER finds the pair in its constellation.

How to test
  1. Here: Go on air.
  2. On the FM-1 (COSMOS 0.23, WiFi on): FX, then ALGO to PLAYER. In a few seconds the two pair up: the FM-1 says YOU PAD WITH … or YOU BELLS WITH … with this page's code, and each hears the other.
  3. Or set the FM-1 as a LISTENER: this page's star appears in the constellation (at the place above); SELECT it, SAVE to listen.
  4. With two of these pages open (two browsers), they pair with each other.
