Install COSMOS 0.21-beta7

Test build: COSMOS 0.20 plus RADIO COSMOS (FX; the radio page), the weather request fixed, the sine table in RAM, the page buttons working from every page (ENV: SEQ looks again), and a diagnosis in GLO. The stable version stays at /COSMOS/install/.

A drone synth for the M-VAVE FM-1, played by the real sky and weather. Installs from this page over USB, in Chrome or Edge. No extra hardware.

Custom firmware, at your own risk. COSMOS is not made or supported by M-VAVE. It runs on fm1-base and felucca-bsp and comes with no warranty.

The way back is always open: the last cards on this page put M-VAVE's own firmware back, over the same USB cable.

1Before you start

Tick each box. The Install button waits until all four are ticked.

2Back up if you come from another firmware

Installing writes over the firmware that is on the FM-1, and what it saved may be lost.

COSMOS itself keeps only its settings (your place, the instrument, the tuning) and the WiFi networks it knows: nothing to back up. Coming from Fantasma or Golana, save a backup from their own install page first (step 2 there): Fantasma, Golana. The official M-VAVE firmware has no backup.

3Connect

Connect the FM-1 by USB and switch it on. Close other programs that use MIDI (a DAW, an editor, another installer tab). The browser asks to allow MIDI with SysEx: allow it.

Not checked yet.

4Install

Install COSMOS 0.21-beta7

The FM-1 checks the package, switches to update mode, writes and restarts; then this page asks it what it runs, to be sure. Its screen shows UPDATING or stays dark while it writes.

COSMOS does not need it: leave it unticked unless you want it. github.com/jvitkauskas/m-bootloader

If it stops: replug the cable and press Install again. The FM-1 stays in update mode until the write is finished, and the page picks it up where it was. When it says done, COSMOS is running.
