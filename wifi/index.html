COSMOS Install

WiFi

Set up your FM-1's WiFi from the computer: type the password on a real keyboard instead of the knobs. Connect the FM-1 by USB with COSMOS running, then press Connect. It works in Chrome or Edge; the browser asks once to allow MIDI: allow it.

      1. The password goes from this page straight to the FM-1 through the USB cable: no server, no internet, and the page keeps nothing.
